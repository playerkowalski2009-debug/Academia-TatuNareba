# Estrutura de CSS

Este projeto utiliza vários arquivos CSS para separar responsabilidades e facilitar a manutenção.

- base.css: reset, tipografia, variáveis e classes utilitárias globais.
- theme.css: regras do modo claro/escuro.
- components.css: navegação, formulários, botões e componentes reutilizáveis.
- pages.css: estilos específicos de seções e páginas.
- sobre.css: estilos da página sobre, mantidos separados para preservar a estrutura original.

Importe os arquivos na ordem desejada para garantir que os estilos sejam aplicados corretamente.
